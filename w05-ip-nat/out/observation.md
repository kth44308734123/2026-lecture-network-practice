# Week 5 · observation

측정 환경: macOS, Apple M4. 주소는 campus-wifi와 폰 테더링 두 네트워크에서 기록했고, DHCP 캡처는 2026-10-20 학교 Wi-Fi(en0)에서 떴다.

---

## Task 1 · 서브넷과 longest-prefix match

/32는 주소가 하나뿐이라 first·last·broadcast를 모두 그 주소로, /31은 RFC 3021처럼 두 주소를 모두 쓸 수 있다고 보고 first = 네트워크 주소, last = 마지막 주소로 돌려준다(broadcast 칸에는 마지막 주소를 넣었지만 broadcast로 쓰이지는 않는다). 점대점 링크에는 상대가 하나뿐이라 broadcast가 필요 없고, 일반 규칙대로 두 주소를 빼면 /31은 쓸 주소가 0개가 되기 때문이다.
10.20.30.70은 10.0.0.0/8(campus), 10.20.0.0/16(eng-building), 10.20.30.0/24(lab-floor), 10.20.30.64/26(lab-rack-2) 네 개에 들어가고(0.0.0.0/0까지 치면 다섯), prefix가 가장 긴 /26이 이겨서 lab-rack-2로 간다. 길수록 더 좁은 범위를 가리키니 더 구체적인 경로다.
길이가 같은데 네트워크가 다른 두 항목은 범위가 겹치지 않아서 한 주소에 같이 매칭될 수 없다. 그래서 충돌은 같은 prefix가 두 번 들어올 때뿐이고, `(네트워크, 길이)`를 키로 써서 나중에 넣은 next hop이 앞의 것을 덮어쓰게 했다(경로 갱신처럼).

## Task 2 · 내가 인터넷 어디에 있나

두 네트워크 모두 사설 주소(172.16.21.153, 172.20.10.8)와 바깥에서 본 공인 주소(163.152.233.21, 106.101.134.207)가 달라서 NAT를 적어도 하나 지난다. 학교 traceroute에서 공인 주소(163.152.233.129) 전에 사설 홉이 둘(172.16.0.2, 192.168.98.132) 있었지만 라우터는 주소를 안 바꾸고 전달만 할 수도 있어서, 두 겹인지는 확인하지 못했다(첫 NAT의 WAN 주소가 공인 주소와 같은지 봐야 한다).
네트워크를 바꾸자 공인 주소는 고려대 블록에서 LG U+ 블록으로 바뀌었다. 공인 주소는 마지막 NAT를 운영하는 쪽의 것이기 때문이다. 사설 주소와 mask(/24 → /28)도 바뀌었는데, 네트워크마다 DHCP 서버가 자기 풀에서 나눠 주기 때문이다.
Discover(frame 2)의 출발지는 0.0.0.0, 목적지는 255.255.255.255였다. 아직 주소가 없으니 출발지에 넣을 수 있는 건 0.0.0.0뿐이고, 서버 주소도 모르니 모두에게 broadcast할 수밖에 없다. lease는 1800초(30분)였다.

## Task 3 · longest-prefix match 빠르게

prefix 길이별로 묶었다. 길이마다 `{네트워크: next hop}` dict를 두고 긴 길이부터 물어서 처음 맞는 곳에서 멈춘다. bench에서 5,000개 prefix, 20,000번 조회가 11.816초 → 0.005초(2371.4배, 틀린 답 0)였고, 메모리는 dict 7개로 213 KB였다(tracemalloc, 선형 리스트는 393 KB). 같은 표로 bit-walk trie를 만들어 보니 4,545 KB였다.
이제 조회 시간은 표에 있는 prefix 개수(5,000)가 아니라 **서로 다른 prefix 길이 개수**에 비례한다. 이 표에는 7개(24·22·20·16·12·8·0, 최대 33개)뿐이고, 조회 한 번에 dict를 평균 2.61번 확인했다(20,000번 중 10,320번은 첫 /24에서 끝남).
trie는 Python에서 0.0158초로 내 방식보다 3.9배 느렸다. 비트마다 Python 명령을 평균 20.4번 실행하지만, dict 조회는 C로 된 해시 한 번이기 때문이다. 그래도 하드웨어가 bit-walk를 쓰는 건, 표가 아무리 커도 32단계를 넘지 않아 모든 패킷이 정해진 시간 안에 끝나고, 단계마다 단순한 메모리 읽기라 파이프라인으로 겹칠 수 있기 때문이다. 해시는 충돌이 나면 시간이 들쭉날쭉해진다.
